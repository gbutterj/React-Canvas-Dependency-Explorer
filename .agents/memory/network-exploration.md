---
name: Network exploration direction
description: Approved UX direction and layout scope for large dependency maps.
---

The user approved a grouped network overview with subsystem drill-down and selected-node dependency/dependent emphasis, rather than making a giant force-directed graph the only view.

**Why:** the product needs interactive exploration at tens of thousands of nodes. The user originally separated layout from graph design and the data model; readable structure and analysis are the priority.

**How to apply:** keep aggregated relationships explicit and make individual dependencies accessible through drill-down. Treat automated layout as a separate enhancement, not a prerequisite or a reason to replace the graph model.
